1. Project Title

PALMYRA — An Ultra-Responsive, Cloud-Native Online Auction and Multi-Vendor Marketplace Platform built with SvelteKit 2, Svelte 5 Runes, Tailwind CSS v4, and Supabase Backend-as-a-Service.

2. Introduction

Modern e-commerce requires dynamic, fair pricing mechanisms alongside rapid visual engagement. Conventional classifieds and fixed-price marketplaces lack dynamic price discovery, whereas legacy auction systems suffer from clunky user interfaces, full-page reloads, distorted images, and poor mobile accessibility.

PALMYRA resolves these deficiencies through a modern, cloud-native architecture combining SvelteKit 2 (with Svelte 5's new reactivity runes) on the frontend and Supabase (PostgreSQL 15, Auth with SSR cookies, and Storage CDN) on the backend.

A flagship engineering highlight of PALMYRA is its Zero-Distortion Media Pipeline: by enforcing a canonical 4:3 aspect ratio across every touchpoint (thumbnails, gallery cards, and hero viewports) via an interactive client-side canvas cropper and WebP compressor, the platform guarantees zero cumulative layout shifts (CLS) and snappy mobile performance.

3. Objectives

  • Real-Time Dynamic Marketplace: Implement competitive live auctions featuring starting bids, Buy-It-Now instant checkouts, reserve thresholds, and dynamic countdown timers.
  • Streamlined "Start Selling" Flow: Facilitate rapid listing creation with return-URL preservation across authentication boundaries, cascading categories, and tag indexing.
  • Standardized 4:3 Media Uniformity: Eradicate image stretching, letterboxing, and layout jumping by constraining all uploads to 4:3 via an interactive canvas cropper.
  • Mobile-First Ergonomics: Guarantee touch targets ≥ 44px, sticky bid bars on mobile viewports, zero horizontal overflow, and responsiveness down to 360px widths.
  • Zero-Trust Security & Row Level Security: Implement PostgreSQL RLS policies that isolate user data, restrict mutations to owners, and enforce cookie session validation.

4. Modules Overview

  • Authentication & Routing Guard Module: Manages session cookies, OAuth code exchanges, protected route barriers, and return-URL navigation.
  • Seller & Listing Creation Module: Powers a multi-step listing wizard with cascading category taxonomy, condition grading, price rules, and slug generation.
  • Media Pipeline & Storage Module: Direct camera capture, multi-image upload queue, interactive 4:3 canvas cropper, WebP compression, reordering, and Supabase Storage CDN distribution.
  • Marketplace Discovery & Live Feeds: Live PostgreSQL queries for active auctions, multi-parameter search, category filtering, sorting, and pagination.
  • Listing Details & Showcase: 4:3 gallery view with thumbnail carousel, live countdown, view count incrementor, and verified seller info.
  • Auction Bidding & Watchlist: Bid placement validation, Buy-It-Now execution, and user watchlisting.
  • User Profile & Reputation: Seller profiles, review score calculation, avatar management, and ratings.

  • 2.2 Interactive 4:3 Canvas Cropper: Image loaded into HTML5 Canvas; user zooms (1x-5x) and pans.
  • 2.3 Offscreen WebP Export: Canvas outputs 800x600 WebP blob at 0.85 compression quality.
  • 2.4 Concurrent Storage Streaming: Blobs streamed in parallel to listing-images/{uid}/{listing_id}/{uuid}.webp.
  • 2.5 Server Transaction: POST action writes atomically to listings, listing_images, and listing_tags.

7.1 Cardinality & Integrity Rules

  • profiles (1) → listings (*): One seller creates multiple listings; deletion cascades.
  • categories (1) → subcategories (*): Taxonomy hierarchy; cascading foreign key.
  • listings (1) → listing_images (*): 1-to-many relationship with order index and primary flag.
  • listings (1) → listing_tags (*): 1-to-many tag index for search filtering.
  • listings (1) → bids (*): Auction bids placed by buyers; records audit trail in bid_history.

9. Functionalities of Each Module

9.1 Authentication & Navigation Guards

Session tokens are managed using HTTP-only cookies verified on every request by src/hooks.server.ts. If an unauthenticated user clicks "Start Selling", the system routes them to /auth/signin?next=/sell, preserving their intended destination across both password-based and OAuth Google sign-ins.

9.2 Seller & Listing Creation Wizard

Located at /sell, this multi-step form guides sellers through:

  • Step 1 (Photos): Multi-upload with native camera option, canvas cropping, and upload progress indicators.
  • Step 2 (Details): Item title, description, cascading category → subcategory selector, condition selection buttons, and tags.
  • Step 3 (Pricing & Dates): Starting price, optional Buy-It-Now price, optional reserve price, inventory quantity, and start/end datetime selectors.

9.3 4:3 Image Cropping & Compression Pipeline

Every photo uploaded must conform to the 4:3 aspect ratio. The ImageCropper provides an interactive viewport with zoom and pan controls. Upon confirmation, the offscreen canvas compresses the image into an 800×600 WebP blob at 85% quality. Files are streamed in parallel to Supabase Storage, and public URLs are assigned.

9.4 Marketplace Discovery & Browse

The homepage (/) and browse page (/listings) execute live PostgreSQL queries against Supabase:

SELECT * FROM listings WHERE status = 'active' AND start_date <= now() AND end_date >= now() ORDER BY current_price DESC;

10. Future Scope

  • Supabase Realtime WebSocket Bids: Live bid stream updates pushed to all active viewing clients without page refreshes.
  • Escrow Payment Gateway: Automated payment hold and release upon confirmed delivery via Stripe Connect.
  • AI-Assisted Item Grading: Computer vision model to evaluate listing photos against declared conditions and flag counterfeit items.
  • Automated Settlement Cron (pg_cron): Automatic state transitions from 'active' to 'sold'/'ended' upon expiration, triggering automated winner notifications.

11. Execution of the Project

11.1 Prerequisites

  • Node.js v20.x or higher
  • pnpm v9 or v10
  • Supabase project instance with PostgreSQL database and Storage enabled

11.2 Environment Configuration

# .env.local PUBLIC_SUPABASE_URL=https://<your-project-id>.supabase.co PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_<your-publishable-key>

11.3 Database Setup

Execute the full migration script located at docs/supabase-setup.sql in the Supabase SQL Editor. Ensure the listing-images bucket is set to Public with authenticated upload RLS policies.

11.4 Running Locally

# Install all dependencies pnpm install # Run development server pnpm dev # Available at http://localhost:5173

11.5 Building for Production

# Run TypeScript and Svelte diagnostics check pnpm check # Create production build pnpm build # Preview build locally pnpm preview
